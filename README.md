# Blackjack Roguelike (MVP / Phase 1)

ブラックジャック×ローグライクの対戦型RPG。スマホ縦画面・PWA。

## 遊び方

ブラックジャックで合計値を作り、その**合計値に対応するスロットのスキル**を発動して戦う。レベル・経験値はなく、強化は「装備スキル（スロット）」と「レリック」だけ。

### ラウンドの流れ

1. **敵が先に引ききって手札を確定**する（最後に引いた1枚だけ裏向き。それ以外は表）
2. そのあとプレイヤーに配牌 → Hit / Stand / 撤退（防御）を選ぶ。敵の公開札を見て判断できる。初手が21でも自動では進まず、Stand を押すまで待つ
3. プレイヤーが勝負（Stand・バースト・撤退）したら、**すぐに裏向きの1枚をめくって**合計値を比較し、**行動順**を決める（敵の追加ドローはない）
   - 合計値が大きい方が先攻、小さい方が後攻
   - 同値は同時攻撃（防御・回復 → 攻撃 → 死亡判定の順）
   - **バーストした側は、スキルが発動せず、受けるダメージが 1.5 倍になる**（プレイヤーも敵も同じ。相手だけが行動する）。両者バーストなら誰も行動しない
4. 両者のスキルを宣言し、**Block を先に付与**（後攻の Block も先攻の攻撃より前に入る）→ 先攻の攻撃・回復 → 後攻の生存確認 → 後攻の攻撃・回復
5. Block（シールド）は戦闘中は持ち越される。HP が0になった側の負け（相打ちはプレイヤー敗北）

撤退（サレンダー）は、自分のスキルを発動せず Block 5 を得る防御行動。敵の手札はすでに確定しているので、そのまま敵だけが行動する（行動順の比較なし）。

### 基本攻撃力（ATK）

プレイヤーも敵も HP とは別に**基本攻撃力（ATK）**を持ち、HP の横に表示される。攻撃スキルのダメージは `floor(ATK × 倍率) + 加算` で決まる（攻撃スキルは最低 1 ダメージ）。

- **プレイヤーの ATK は、スキルが発動するスロットで変わる**: 11以下=1 から、スロットが1つ上がるごとに +1（12=2 … 15=5 … 20=10、21=11）。祭壇・砥石・祠の強化は、どのスロットにも同じだけ足される（標準の強化なしなら、スロット15 の ATK 5 が従来の固定値と同じ）。合計値が高いほど、同じスキルが強くなる。HP の横の ATK は、いまの合計値でのATK（合計が分からない間は `1〜11` の範囲）。
- **敵の ATK は固定**（スライム 3、骸骨兵 4 など）。

| スロット（初期） | スキル | 式 | そのときの ATK | ダメージ |
|---|---|---|---|---|
| 未設定の合計値 | 通常攻撃 | ATK×1 | 合計値 − 10（最低1） | 例: 13 → 3 |
| 11以下 | 小攻撃 | ATK×0.5 | 1 | 1（最低1） |
| 15 | シールド | Block 6 | — | — |
| 18 | 盾 | Block 8 | — | — |
| 20 | 大攻撃（剛） | ATK+5 | 10 | 15 |
| 21（固定） | 会心の一撃（会） | ATK×3 | 11 | 33 |

- ATK の強化（血塗れの砥石 +2、祠の力 +1、祭壇の刃 +1〜3）は、全攻撃スキル・全スロットに効く。
- **レリックでスキルの効果を変えられる**: 剛力の腕輪（大攻撃が ATK×2+5）、巨人の血（小攻撃が ATK×3）、覇王の宝珠（会心の一撃が覇王の一撃 = ATK×4 + Block 8）。
- **Block は戦闘中は持ち越される**（ラウンドをまたいで残り、戦闘が終わると消える）。
- **発動するスキルの大きな表示**: バトル画面のスロット表の下に、現在の合計値で発動するスキルが、アイコン・名前・効果の数値で大きく出る（例: `大` **大攻撃** `15ダメージ`、`守` **シールド** `+6 Block`。空きスロットは「通常攻撃」と明記。スキルが変わると弾む）。レリックの補正・敵の特性・敵の Block 吸収後の値も反映される。
- **戦闘ログ欄はない**（ほとんど見られず、場所をとるため）。行動順は敵の舞台に帯で出る（例: `スライムが先攻  18 ＞ 15`、バースト、同値、撤退）。ダメージの数字の下には、Block が防いだ量とバーストの倍率が添えられる（例: `-7  Block 5・バースト×1.5`）。過去の記録は上の「記録」ボタンで見返せる。読み上げ（スクリーンリーダー）には、見えない領域に同じログが出る。
- **敵の技**: バトル画面の「敵の技」ボタンで、敵の ATK・特性と、全スロット（11以下〜21）のスキルを実数値つきで確認できる（敵の ATK は固定）。

### メタ進行（負けても少し強くなる）

セーブは端末の `localStorage`（同じ端末・ブラウザ内のみ持ち越し）。

- **魂片**: 冒険が終わるたびに、負けても獲得（到達した段 ×2 + 倒した敵 ×4、クリアで +40）。
- **魂の祭壇**（タイトルから）で魂片を使って恒久強化: 強き肉体（初期HP +5×最大5）/ 研ぎ澄まされた刃（初期ATK +1×最大3）/ 守りの心得（戦闘開始時Block +2×3）/ 安らぎの心得（宿屋回復 +10%×3）/ 見る目（報酬スキルの選択肢 +1）/ 初期スキル枠（+1×2）。
- **図鑑**: 入手したスキル・レリックが記録される。図鑑に載ったスキルは報酬に出やすくなる（重み ×2）。
- **出撃準備**（タイトルから。設定は保存され、「冒険を始める」で使われる）: 図鑑のスキルを**最初から装備**できる。
  - 全スロット（11以下〜21）の一覧を見ながら、変えたいスロットをタップ → 下から出る一覧でスキルを選ぶ（1ステップ。レア度の高い順、効果は実数値つき）。
  - 変えられるのは 12〜20 のうち「初期装備枠」の数だけ（初期 1、祭壇で最大 3）。初期装備（15=シールド / 18=盾 / 20=大攻撃）も置き換えられ、「初期装備に戻す」で戻せる。11以下と 21 は固定。
  - 枠がいっぱいのときは、選べない理由が一覧の上に表示される。タイトルの「出撃準備」ボタンには `装備 使用数/枠数` が出て、設定できるものがあると光る。

### レア度

スキルとレリックには **コモン / レア / レジェンド** があり、枠の色と光り方で分かる（コモン=くすんだ銅色、レア=青い光、レジェンド=金橙の輝き）。報酬の抽選ではレア度が高いほど出にくい（重み 6 : 3 : 1）。

### 敵のスロット表

スロット表は、合計値がたまるにつれて**左から順に、下から光が満ちて点灯するメーター**になっている。各マスには**効果の数値**（攻撃=ダメージ数、回復=`+数`、Block=`B数`。レリック・敵の特性・相手のバーストを反映）が添えられる（いちばん右の点灯が、いま発動するスロット。バースト・合計不明のときは点灯しない）。敵のスロット表もプレイヤーと同じ形式で敵エリアに表示されるが、「N以上になるまで引く」敵（`EnemyAI.standOn`）は **N 未満のスロットを出さない**（スライム14〜21 / 骸骨兵15〜21 / 屍食鬼16〜21 / 蝙蝠・黒竜18〜21。弱い敵ほど低い合計で止まり、強い敵ほど高い合計まで引く）。表を見るだけで、敵の個性が分かる。最後の1枚が伏せられている間は、合計不明で何も点灯しない。詳しい数値は「敵の技」ボタン。

### ステージ（ステージ1「忘れられた地下墓所」）

駒を1度に1マスずつ進める。途中で3つの道に分かれ（左=運試し・中=安全・右=スキル稼ぎ）、大広間で合流し、再び分岐してボス（黒竜）のマスへ。

| マス | 効果 |
|---|---|
| 敵 | 戦闘。勝つとスキルを3択で獲得し、そのままスロットへセット |
| 宝箱 | レリックを3択で獲得 |
| 宿屋 | 最大HPの50%回復 |
| 祠 | ランダム効果: 最大HP+8 / HP全回復 / スキル獲得 / 血の契約（HP-10でレリック）/ 呪い（HP-10）/ 静寂 |
| 何もなし | 通過するだけ |
| ボス | 黒竜。倒すと踏破 |

**編成（スキルの付け替え）**: スキルは取得時にセットし、マップ画面の「編成」でいつでも付け替えられる。**スロットをタップ → 持ち物から置くスキルを選ぶ**（1ステップ。外すのも同じ選択シートから。外したスキルは持ち物に残る）。スキル獲得直後は、置くスキルが上に表示され、置きたいスロットをタップするだけ（置くと自動でマップに戻る）。

戦闘後の自動回復はなく、HP は持ち越し。回復は宿屋・祠が頼り。済みのマス（倒した敵・開けた宝箱など）は再発動しない。

敵: スライム / 骸骨兵（骨の鎧）/ 大蝙蝠（同値なら先攻）/ 屍食鬼（HPを削ると回復）/ 黒竜（攻撃+3）

レリック: 鋼の胸当て・堅牢の盾・命の蝋燭（コモン）/ 血塗れの砥石・吸血の牙・身代わりの人形・運命の指輪・疾風の靴・剛力の腕輪・巨人の血・解錠の鍵（レア）/ 覇王の宝珠・封印の鍵（レジェンド）

### ステートマシン

```
Init → Deal(敵に初手2枚) → EnemyAction(敵が引ききる・最後の1枚だけ伏せ) → PlayerDeal(自分の配牌)
     → PlayerAction ─ Hit ─→ PlayerAction
                    ├ Stand / バースト ─→ Initiative（伏せカードをめくる）
                    └ 撤退 ─→ Surrender ─→ Initiative（敵のみ行動）
Initiative → FirstAction → SurvivalCheck → SecondAction → CheckDeath → Deal / 終了
                         └ (同時攻撃・後攻なし) → CheckDeath
```

演出のウェイトは `src/core/battle/pace.ts` の `PACE` にまとめてあり、バトル全体のテンポはここだけで調整できる（テストでは `BattleOptions.pace` で即時解決）。
敵のバースト音は、伏せカードがめくられる行動順の発表まで鳴らさない（バーストの有無を先に漏らさないため）。

### 音（`src/audio/AudioManager.ts`）
BGM・SE は Web Audio で合成する（外部ファイルなし）。タイトル画面の BGM は、起動時に準備しておき、ブラウザが自動再生を許す環境ではすぐ鳴る。許さない環境（iPhone など）では、**最初のタップ（どこでも）で鳴り始める**（タップする前は無音。これはブラウザの制限で避けられない）。タイトルと戦闘画面の ♪ ボタンで、オン/オフを切り替えられる（保存される）。
効果音の方針: カードを配る音（`deal`）は軽く落ち着いた紙の音で、毎回ほんの少し高さを変える。伏せカードをめくる音（`flip`）は別の音（上へ動く「しゅっ」）。Block を得る音（`block`: 低いどっしりした響きに、澄んだ金属の余韻が上へ立ち上がる）・Block が攻撃を防いだ音（`guard`: 短く硬い「ガキン」）・回復の音（`heal`: やさしい鈴の4音が上がる）は、それぞれ別の音。これらは、**実際に起きたとき**の通知（`onBlockApplied` / `onHealApplied`）で鳴らす（`onBlockGained` / `onHealed` はスロット表や予測の計算のたびにも発火するので、音には使わない）。
スリープ・画面ロック・別アプリから戻ったときは、戻った時に再開を試み、それでも止まったままなら次のタップで再開する。iOS で `interrupted` のまま戻らない場合は、タップの中で `AudioContext` を作り直す（`tests/audio.test.ts`）。

## イベントフック（レリック拡張）

`machine.bus.on(name, handler, priority?)` で購読。ハンドラはペイロードを書き換えるか、新しいペイロードを return すると値を改変できる。

```ts
bus.on('onDamageCalculated', (p) => ({ ...p, damage: p.damage + 2 }));                // ダメージ改変
bus.on('onInitiativeDecided', (p) => ({ ...p, turn: { ...p.turn, first: 'player' } })); // 行動順の改変
bus.on('onSkillActivated', (p) => ({ ...p, skill: null }));                           // スキルを不発に
bus.on('onBlockGained', (p) => ({ ...p, amount: p.amount + 3 }));                     // Block 獲得量
```

フック一覧: `onBattleStart` `onRoundStart` `onDealt` `onCardDrawn` `onStand` `onBust` `onInitiativeDecided` `onSkillActivated` `onDamageCalculated` `onDamageDealt` `onBlockGained` `onHealed` `onSurrender` `onRoundEnd` `onBattleEnd`

## ルールの解釈（仕様の補足）

- クリティカルという概念はない。21 のスキル（会心の一撃）も ATK×3 の通常のダメージ（ATK はスロット21 の 11）
- バーストの被ダメージ倍率（`RuleSet.bustDamageMultiplier`、初期値 1.5）は、攻撃ダメージの計算の「レリック・敵の特性の補正のあと、Block が吸収する前」に掛かる（端数は切り捨て。例: 溶解 8 → 12。Block 5 があれば HP は 7 減る）。両者バーストや、身代わりの人形で防いだバーストは誰も攻撃しないので、倍率の出番はない
- 予測ダメージにも倍率は反映される。ただし敵の伏せカードがあるうちは等倍で表示する（敵がバーストしているかを漏らさないため）
- ディーラーはソフト17でもStand
- 山札はバトル中使い回し、残り15枚未満でラウンド開始時に再シャッフル（`RuleSet.reshuffleThreshold`）
- 難易度: 「16未満でヒット」だけの単純なボットで、スロットごとの ATK を入れる前は約1割、入れた後は約3〜4割がクリア（`vite-node` で試算）。スロットが高いほど強くなったため、合計値を作るほど有利になる。敵の公開札を見て判断できる実際のプレイヤーは、これより上がる想定
