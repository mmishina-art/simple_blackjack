# 作業の始め方・終わり方（Claude Code と Antigravity の共通の手順）

このリポジトリは、**Claude Code（Web 版）** と **Antigravity（Gemini）** の 2 つの AI で開発している。
2 つの AI は、互いの会話を見られない。**共有できるのは、リポジトリのファイルと git の履歴だけ**なので、
作業の状態は `docs/HANDOVER.md`（引き継ぎメモ）に書いて渡す。

- Claude Code では `/start`・`/finish`（`.claude/skills/`）、Antigravity では同じ名前のワークフローで、この手順を呼び出す。
- 「作業開始」「続きから」「作業終了」「終わり」のような言葉で頼まれたときも、同じ手順に従う。

## 始めるとき（/start）

1. 最新の `main` を取り込む（`git fetch origin main` → 作業ブランチなら `main` を取り込む）。
2. `docs/HANDOVER.md` を読む（前回の状態・やりかけ・次にやること・注意）。
3. `git log --oneline -15 main` で、最近の変更を見る。**メモのあとに、もう一方の AI が進めた変更がないか**を確かめる（メモに書かれていない変更があれば、それも状態に入れる）。
4. 開いている PR と、作業ブランチの状態（`git status`・push していないコミット）を確かめる。
5. 「今の状態」と「最初に着手する作業の案」を短く示し、オーナーの確認を待つ（CLAUDE.md の「実装の前に、要望の解釈を見せる」と同じ。確認は選択式で）。

## 終わるとき（/finish）

1. `git status` と push していないコミットを確かめる。コミットしていない変更があれば、内容を示す。
2. `docs/HANDOVER.md` を書き換える（下の形）。**作業中の PR があれば、そのブランチに入れる**（メモのためだけの PR は作らない。PR がなければ、オーナーに聞いて小さな PR にする）。
3. チャットにも、同じまとめを出す（今日やったこと・残っていること・次にやること・再開のときの指示文）。
4. **コミット・push・マージは、オーナーの確認を取ってから**（選択式で聞く。自分の判断でマージしない）。

## 2 つの AI で作業するときの約束

- **同じブランチを、2 つの AI で同時に触らない。** 作業ブランチを始めるときは、HANDOVER の「やりかけ」に書く。
- **始める前に、必ず最新の `main` を取り込む。** もう一方の AI がマージしているかもしれない。
- `package.json` の `version` は、`main` の最新から上げる（同じ番号を 2 つの AI で付けない）。
- ルールを変えたら、`CLAUDE.md`（共通の指示書）と README を更新する。どちらの AI も `CLAUDE.md` に従う。

## HANDOVER.md の形

```
# 引き継ぎメモ
更新: YYYY-MM-DD（Claude Code / Antigravity）・版 vX.Y.Z

## 今の状態
## やりかけ（ブランチ・PR・だれが）
## 次にやること（優先順）
## 注意・気づいたこと
## 再開のときの指示文
```
