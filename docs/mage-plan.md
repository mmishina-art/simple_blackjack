# 魔導士の作り直し（仕様）

決めたこと（2026-10-19、オーナー）: 魔導士に「**札のマークで属性が決まる**」を入れ、スキルを半分作り直す。
目的は 2 つ: ① 戦士とは違う迷いどころ（合計だけでなく、マークも狙って引く）を作る。② 強すぎるのを直す（v0.114 の試算でクリア 33%。戦士は 12%）。

## 1. 札のマークで属性が決まる

- 魔導士の攻撃・障壁の属性は、**手札の最後の 1 枚のマーク**で決まる: ♥ 炎・♠ 氷・♣ 雷・♦ 無属性。
  - 無属性: 弱点を突かない（×2 にならない）。敵に吸収もされない。
- スキル自体には属性を持たせない（属性はマークで決まる）。決まった属性を持つのは、敵の攻撃と、下の「残すスキル」だけ。
- 画面: 魔導士のときは、合計値の行に「今の属性」（例: `♥ 炎`）を出す。色だけに頼らず、文字でも出す。敵の弱点と合っていれば「弱点」と出す。
- 戦士には関係しない（今のまま）。

## 2. スキル（18 種 → 13 種）

属性つきの攻撃は「炎・氷・雷を 1 つずつ」並べる作りをやめ、**攻撃の形**で分ける。数字は今のスキルから引き継ぐ。

| 新しいスキル | レア度 | 効果 | 元のスキル |
|---|---|---|---|
| 魔弾 | コモン | 攻撃 POW+1 | 火球・氷柱・雷撃 |
| 連弾 | レア | 2 回攻撃 POW×0.8+1 | 双雷 |
| 魔槍 | レア | 攻撃 POW+3・ブロック無視 | 雷槍 |
| 大魔法 | レア | 攻撃 POW+5（初期の 20） | 紅蓮術・吹雪 |
| 共鳴弾（新） | レア | 攻撃 POW+2。**手札が全部同じマークなら 2 倍** | なし |
| 天変 | レジェンド | 攻撃 POW×2+5 | 隕石召喚 |
| 三連星 | レジェンド | 3 回攻撃 POW×0.7+2 | 神罰の雷・絶対零度 |
| 属性の障壁 | コモン | ブロック POW+2 + マークの属性を吸収 | 炎・氷・雷の障壁 |

残すスキル（今のまま）: 元素吸収、星喰らい（攻撃の属性はマークにする）、魔力の盾、反鏡の陣、神鏡の結界。21 の大魔導（祠の強化 → 星霊魔導 → 創世魔導）も今のまま。

- 初期スロット: 11 小攻撃・13 魔弾・15 薬草・16 属性の障壁・18 魔弾・20 大魔法・21 大魔導。
- ドロップ表（`MAGE_ENEMY_DROPS`）・ショップ・`MAGE_STARTER_SKILLS`・README・`tests/mage.test.ts` を合わせる。
- **保存データ**: 図鑑（`bj-meta-v1` の `codex.skills`）に、なくしたスキルの ID が残る。読み込みで捨てるか、新しい ID に置き換える（記録を消さない）。

## 3. バランス

- 目標: 祭壇の強化なしで、魔導士のクリア 5〜8%（1 回クリアしてから使えるので、戦士より少しだけ易しくてよい）。
- 実装したら `CHAR=mage npx vite-node tools/sim-balance.ts 600` で測る（Claude Code が担当）。強すぎるときは、魔導士の HP（30 → 24 など）で合わせる。
- 戦士も v0.114 でクリア 12%（目標 5% 前後）。第 3 階層が簡単すぎる（黒竜に勝率 100%）。魔導士とは別に直す。
