## 注意・気づいたこと

- **`main` はブランチ保護で守られている**（2026-10-25 に設定。GitHub の Rulesets `protect-main`）。PR を通さない push と、CI（`test`）が赤い PR のマージは、GitHub が拒否する。作業ブランチ → PR → CI が通ってからマージする（`CLAUDE.md`）。v0.107〜0.113 は PR を通さずに `main` へ入っていたので設定した。
- **シミュレーションの不具合**: `tools/sim-balance.ts` の `STAGE_OF`（階層ごとに敵を強くする `ES1`〜`ES3` が使う表）に、新しい敵 7 体（重装の盾兵・ミミック・賭博師・腐肉の巨兵・溺れた騎士・鋼鉄のゴーレム・溶岩の大蛇）がなく、第 1 階層として扱われる。地図のデータから階層を読むように直す。
- 公開（`pages.yml`）と PR のテスト（`test.yml`）は、どちらも Node.js 24（v0.116 のあとにそろえた）。
- `tools/sim-balance.ts` は `CHAR=mage` で魔導士を測れる（`PLAYER_HP=24` で HP も変えられる）。v0.116 の試算（600 回・祭壇の強化なし。目標は戦士 5% 前後・魔導士 5〜8%）:

  | 条件 | クリア |
  |---|---|
  | 戦士 | 12% |
  | 魔導士（今のまま） | 36% |
  | 魔導士・ローブの反射なし | 30% |
  | 魔導士・吸収なし | 22% |
  | 魔導士・吸収はダメージ 0 だけ（回復なし） | 30% |
  | 同じ + HP 24 | 17% |
  | 魔導士・HP 24 / HP 20 | 20% / 13% |
  | 魔導士・弱点の倍率 1.5（HP 30 / 24） | 32% / 17% |

  強さの原因は、属性の吸収（とくにダメージが 0 になること。21 の大魔導の全属性吸収と、属性の障壁）。反射と弱点の倍率は、あまり効いていない。ボットはマークを狙って引かないので、人が遊ぶともっと強いかもしれない。
- PR は 1 つの目的にする。#111（魔導士の作り直し）には、戦闘画面の見直し（v0.114）もいっしょに入っていた。

- `tools/sim-balance.ts` のボットは、危険（`FATAL_RISK`）・予告（`OMEN_RISK`）・ゴールドの選択（`GOLD_PICK`）を読む。ルールを変えたら、ボットも合わせる。
