# 絵のプロンプト（Gemini 用）

最初に作ったモノクロのスライム（`slime`）の**線の画風（細いペン画・銅版画）のまま、色を付けた**絵で、14体（スライムも描き直す）をそろえるための頼み方。**同じ会話の中で、1体ずつ順に頼む**と、画風がそろいやすい。最初に、モノクロのスライムの絵を貼って「この絵の線の画風のまま、色を付けて」と伝えると、さらにそろう。**スライムから先に描いて、色の付き方を決める**とよい（2体目からは、カラーのスライムの絵を見本に貼る）。

できた画像は、**Google ドライブの「blackjack-enemies」フォルダ**に、ファイル名を **ID**（例: `skeleton.png`）にして保存する。プロンプトにも保存先とファイル名を入れてある。Gemini がドライブに直接保存できないときは、画像をダウンロードして、自分でそのフォルダに入れる。入れたら Claude に「ドライブに入れた」と伝えると、そこから取り込む。背景は黒のままでよい（ゲーム側で透明にする: `python3 tools/art.py <画像> <ID>`）。

## 共通の指定（毎回、最初に付ける）

```
ダークファンタジーのローグライクゲームの敵キャラクターを1体描いてください。
画風: 添付した絵と同じ、細いペン画・銅版画のような黒い線とハッチング。そこに色を付ける（手彩色の銅版画のように、線を生かした落ち着いた塗り）。色は、彩度をおさえた暗い色（くすんだ緑・錆びた茶・骨の黄ばんだ白・鈍い鉄色・乾いた血の赤など）が中心。目の光・炎・溶岩など、光るものだけは鮮やかに。濡れた所や金属には、鋭いハイライト。シリアスで不気味、かわいさは入れない。
雰囲気: 添付したモノクロの絵の、暗く重い不気味さはそのまま保つ。色を付けても、明るく派手な絵・アニメ調・ゲームのキャラクターらしいかわいさにはしない。全体は暗い色調のままで、影は深い黒のまま残す。
構図: 1体だけを中央に、全身。正面〜やや左向き。顔（目）は画像の中央よりやや上。上下左右に少し余白。光は左上から。
背景: 真っ黒の単色。地面の影・床・文字・枠・サイン・透かしは入れない。
大きさ: 横 1000 × 縦 800 ピクセル（横長 5:4）。
保存: できた画像を、Google ドライブの「blackjack-enemies」フォルダに、下の「ファイル名」で保存してください（フォルダがなければ作ってください）。
```

## 色について

**雰囲気（暗く重い不気味さ）は、モノクロのスライムのまま保つ**。線はモノクロのスライムと同じペン画・銅版画のまま、色を付けた形にしている。色は暗くおさえて、光るもの（目・炎・溶岩・炉）だけ鮮やかにする。戦闘の舞台は暗いので、敵の体の色は、背景の黒に沈みすぎない明るさにしてもらう。

# 敵以外の絵（タイトル・戦闘の舞台の背景・場面の挿絵）

敵の絵と同じ会話で続けて頼むと、画風がそろう（見本に、できあがった敵の絵を1枚貼る）。保存先は、敵と同じ **Google ドライブの「blackjack-enemies」フォルダ**。

## 共通の指定（毎回、最初に付ける）

```
ダークファンタジーのローグライクゲームの画面に使う絵を描いてください。
画風: 添付した敵の絵と同じ、細いペン画・銅版画のような黒い線とハッチングに、手彩色の銅版画のような落ち着いた色。彩度をおさえた暗い色が中心で、灯り・炎・月の光など光るものだけは鮮やかに。
雰囲気: 暗く重い不気味さ。明るく派手な絵・アニメ調・かわいさにはしない。影は深い黒のまま残す。
入れないもの: 人物（指定したもの以外）・文字・枠・サイン・透かし。
保存: できた画像を、Google ドライブの「blackjack-enemies」フォルダに、下の「ファイル名」で保存してください。
```
