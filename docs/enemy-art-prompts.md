# 敵の絵のプロンプト（Gemini 用）

スライム（`slime`）の絵に画風をそろえるための頼み方。**同じ会話の中で、1体ずつ順に頼む**と、画風がそろいやすい。最初に、できあがったスライムの絵を貼って「この絵と同じ画風で」と伝えると、さらにそろう。

できた画像は、ファイル名を **ID**（例: `skeleton.png`）にして渡す。背景は黒のままでよい（ゲーム側で透明にする: `python3 tools/enemy-art.py <画像> <ID>`）。

## 共通の指定（毎回、最初に付ける）

```
ダークファンタジーのローグライクゲームの敵キャラクターを1体描いてください。
画風: 添付したスライムの絵と同じ。モノクロ（黒と灰色の濃淡だけ）の、細いペン画・銅版画のような線とハッチング。濡れた所や金属には、白い鋭いハイライト。シリアスで不気味、かわいさは入れない。
構図: 1体だけを中央に、全身。正面〜やや左向き。顔（目）は画像の中央よりやや上。上下左右に少し余白。光は左上から。
背景: 真っ黒の単色。地面の影・床・文字・枠・サイン・透かしは入れない。
大きさ: 横 1000 × 縦 800 ピクセル（横長 5:4）。
```

## 1体ずつの指定（共通の指定のあとに付ける）

### 第1階層「忘れられた地下墓所」

**`skeleton` 骸骨兵**
```
敵: 骸骨兵。錆びた兜と肩当てを付けた、古い兵士の骸骨。ひび割れた丸い木の盾と、刃こぼれした剣を持つ。骨は硬く分厚く、鎧のように見える（特性「骨の鎧」: 受けるダメージが減る）。眼窩の奥に、小さな光る点。
```

**`bat` 大蝙蝠**
```
敵: 大蝙蝠。人の背丈ほどの巨大な蝙蝠。翼を大きく広げ、翼膜はところどころ裂けている。口を大きく開けて叫んでいる（特性「超音波」）。鋭い牙、小さく光る目、とがった大きな耳。
```

**`ghoul` 屍食鬼**
```
敵: 屍食鬼。痩せこけて骨の浮いた、灰色の人型の怪物。背を丸めて前かがみ。長く汚れた爪、裂けた口と不ぞろいの牙、口元に黒い血のしみ（特性「屍の渇き」: 傷つけるたびに回復する）。白く濁った目。
```

**`knight` 墓守の騎士（第1階層のボス）**
```
敵: 墓守の騎士（ボス）。重い全身鎧の巨大な騎士。大きな塔のような盾と、両手持ちの大剣。兜の細い隙間の奥に、冷たい光。鎧には傷と古い紋章、肩にぼろぼろの外套。ほかの敵より大きく、威圧感のある構え（特性「重装」）。
```

### 第2階層「沈んだ大聖堂」

**`merman` 沼の魚人**
```
敵: 沼の魚人。魚の頭を持つ人型。ぬめった鱗、背びれと腕のひれ、水かきのある手。銛を構えている。体から沼の藻と水がしたたる（特性「再生」）。丸く感情のない魚の目。
```

**`gargoyle` ガーゴイル**
```
敵: ガーゴイル。大聖堂の屋根にいた石像の悪魔が動き出したもの。うずくまる姿勢、たたんだ石の翼、ねじれた角、牙をむいた口。肌はひび割れた石で、苔と欠けがある（特性「石の肌」: 受けるダメージが減る）。
```

**`wraith` 亡霊**
```
敵: 亡霊。ぼろぼろの布をまとった、実体のない霊。下半身は煙のように薄れて消えている。頭巾の中の顔は闇で、目だけが白く光る。細長い手を伸ばしている。まわりに霜と冷たい霧（特性「冷気」）。
```

**`iron_golem` 鋼鉄のゴーレム**
```
敵: 鋼鉄のゴーレム。鉄板をリベットでつなぎ合わせた、重い人型の機械の巨人。巨大な腕と拳、胸に小さな窓のような炉の光。分厚い装甲が何枚も重なっている（特性「鋼の守り」）。顔は鉄仮面で、細い目の光。
```

**`serpent` 深淵の海蛇（第2階層のボス）**
```
敵: 深淵の海蛇（ボス）。黒い水からとぐろを巻いて立ち上がる、巨大な海蛇。ぬめった鱗、頭のまわりのひれ、大きく開いた口に何列もの牙。体に海藻と古い傷。水しぶき。ほかの敵より大きく、威圧感がある（特性「再生」）。
```

### 第3階層「竜の巣」

**`flame` 炎の精霊**
```
敵: 炎の精霊。燃えさかる炎そのものでできた人型。輪郭は揺らめいて、ところどころ火の粉になって散る。胸の奥の核がいちばん明るい。顔は炎の中にうっすら浮かぶ、怒った表情（特性「燃焼」: 攻撃が強い）。モノクロなので、炎は白と灰色の明るさで表す。
```

**`golem` 溶岩ゴーレム**
```
敵: 溶岩ゴーレム。黒い岩のかたまりでできた巨人。岩の割れ目の奥から、溶けた溶岩の光がもれる（モノクロなので白く光らせる）。重く、肩と腕が大きい。体から煙が立ちのぼる（特性「石の肌」）。
```

**`imp` 業火の悪魔**
```
敵: 業火の悪魔。人より小柄な悪魔。こうもりの翼、ねじれた角、長い尾、三叉の槍。ずる賢そうに口の端で笑っている（特性「悪魔の取引」）。足元から炎と煙。細く光る目。
```

**`dragon` 黒竜（最後のボス）**
```
敵: 黒竜（最後のボス）。巨大な黒い竜。翼を大きく広げ、首をもたげて見下ろしている。黒く分厚い鱗、角のある頭、牙のすき間から炎と煙がもれる（特性「竜の息吹」: 攻撃が強い）。すべての敵の中で、いちばん大きく、威圧感がある。
```

## 色について

いまはスライムに合わせて、すべてモノクロ（黒と灰色）にしている。炎・溶岩・目の光だけ色を付けたいときは、共通の指定の「モノクロ（黒と灰色の濃淡だけ）」を「黒と灰色の濃淡。炎・溶岩・目の光だけ、くすんだ橙」に変える。
